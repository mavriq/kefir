
# kefir

Утилита для простого создания эфемерных контейнеров `kubectl-efir`

Предоставляет минимальное автодополнение, а также UI для выбора:
- Pod-а, к которому действительно нужно подключиться
- контейнера, к NS cgroup которого нужно подключиться
- volumes, существующие в Pod-е, которые нужно подключить к будущему эфемерному контейнеру
