# Жизненный цикл приложения

- при запуске приложения, при выполнении команды `attach` в командной строке указывается НС + Pod к которому надо подключиться
  (в перспективе - возможен вариант указания по маске, с возможностью выбора из списка подходящих)
- после этого в интерактивном меню выбирается какой образ для подключения использовать
- далее выбирается какие волумы монтировать (по умолчанию - все)
- далее выбирается к PID-NS какого контейнера подключаться (по умолчанию - первого)
- после этого выполняется подкючение (пока - выполняется `kubectl debug ...`)
